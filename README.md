# Zedu Channel Motion — HNG15 Whimsical Design Task 2

A standalone, simulated recreation of Zedu’s Channel Directory. It is **not** connected to Zedu production and does not join real channels.

## Signature animation

Click **Join +** on a channel you haven't joined. An animated full-screen welcome reveal appears with a bouncing channel symbol, confetti burst, expanding rings, and a clear **Explore channels** button. The overlay also closes automatically, and Escape dismisses it. The channel updates to **Joined** in the UI.

Other small effects: staggered channel entrances, hover lift, smooth search filtering. Respects reduced-motion preferences and works on mobile.

## Try it

Open `index.html` in a browser. Search for `design`, `bug-reports`, or `engineering`; click **Join +**. Reload the page to reset demo data.

## Deploy

Upload `index.html` and `README.md` to your existing GitHub repository and commit. If Vercel is connected to that repository, it will redeploy automatically. Static HTML/CSS/JS; no framework or build command needed.
